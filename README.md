# PRIME SCALP CRYPTO

Cloud-based automated cryptocurrency trading SaaS with an Android client (APK/AAB), secure exchange API connections, strategy and risk engines, subscription management, and auditable execution.

> Live trading remains disabled until each exchange integration, security control, and release gate is independently verified. No simulated orders, synthetic fills, or fabricated P&L are permitted in the production path.

See `docs/ARCHITECTURE.md` and `docs/ROADMAP.md` for the initial engineering plan.
